## 4. 飞书知识库自检

**检查方式**：使用 Bot 身份只读调用飞书知识库接口，不写入、不申请权限、不触发登录。

| 检查项 | 命令 | 结果 |
| --- | --- | --- |
| Bot 身份 | `lark-cli auth status --json` | `ready` |
| 用户身份 | `lark-cli auth list` | `No logged-in users` |
| 身份限制 | `lark-cli config strict-mode` | `bot` |
| 列知识空间 | `lark-cli wiki +space-list --as bot` | 失败，`code=99991672` |
| 列知识库节点 | `lark-cli wiki +node-list --space-id <已知空间> --as bot` | 失败，`code=99991672` |

失败原因为应用未申请知识库相关 scope，返回的 `missing_scopes` 包括：

- `wiki:wiki`
- `wiki:wiki:readonly`
- `wiki:space:retrieve`
- `wiki:node:retrieve`

**结论：知识库自检不通过。** 当前既不能列出知识空间，也不能读取已知空间下的节点；这与仓库 `AGENTS.md` 中「归档到内部知识库当前不可用（飞书 user 身份未开通）」的记录一致。

**恢复路径（需人工操作）**

1. 由应用开发者在飞书开放平台为应用申请并发布上述 wiki scope；若还要读文档正文，再补 `docx:document:readonly`。
2. 经用户明确确认后，把 `strict-mode` 从 `bot` 切换为 `off` 或 `user`，完成用户扫码登录。
3. 重新执行 `lark-cli wiki +space-list` 与 `lark-cli wiki +node-list` 验证；两条命令返回 `ok: true` 才算通过。

本轮未执行第 1、2 步：前者需要开发者后台权限，后者属于配置变更且 CLI 明确要求人工确认。

### 5.4 推荐

1. **最低首年成本**：京东云轻量 4 核 8G，5M / 500 GB 月流量 / 180 GB 盘，450 元/年。适合流量不大、能接受第三方信息需二次核验的场景；下单前务必在京东云官网确认活动资格与续费价。
2. **综合最推荐**：腾讯云轻量 4 核 8G，12M / 2000 GB 月流量 / 180 GB 盘，880 元/年（首单）。带宽和流量在同价位里最宽，适合建站、API、轻量服务；活动信息标注截止 2026-11-30。
3. **阿里云生态用户**：u2a 4 核 8G，898.20 元/年（1M）。如果业务需要公网访问，1M 偏小，建议直接看 5M 版 1204.20 元/年。
4. **长期持有**：先问清续费价。京东云 3 年 1798 元（约 599 元/年）在 500 GB/月流量够用时更划算；腾讯云 3 年 6 折、阿里云 3 年目录价也可对比。
5. **海外/免备案**：Contabo €5.50/月最便宜，但需接受跨境延迟、外币支付和售后时差；DigitalOcean $48/月更稳但更贵。

### 5.5 购买前必查

- 是否满足「新用户/首单」资格；同一实名主体通常限购 1 台。
- 首年价与续费价分别是多少；活动是否自动续费、到期是否涨价。
- 带宽是固定带宽还是按流量计费；月流量包超额单价。
- 系统盘是否包含在套餐内；数据盘、快照、备份是否另收费。
- 中国大陆节点建站需 ICP 备案；海外节点无需备案但国内访问慢。
- 实际下单页价格与本文表格可能不同，以支付页为准。
